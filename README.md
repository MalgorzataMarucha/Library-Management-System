# Library Management System
A simple library management system built with native PHP and a MySQL database. 

## Features
- **Libraries and Books Management**: Browsing information, opening hours, and book copies.
- **Copies Catalog**: Adding, editing, and deleting copies with status tracking (rented / reserved).
- **Readers and Fines Management**: Managing reader profiles and fine systems.
- **Security**: Using prepared statements for protection against SQL Injection.

## Technologies
- PHP 8+ (MySQLi)
- MySQL / MariaDB
- HTML5, CSS3
